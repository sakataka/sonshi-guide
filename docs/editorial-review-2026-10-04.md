# 校正・校閲記録（2026年10月4日）

以下は初回校閲の記録。今回の追加再校と、更新された確認結果は末尾の「追加再校」に記す。

## 対象と編集方針

十三篇の進言・原文・書き下し文、名句12件、全篇の余話と「こんなところにも」、附録「孫子という人」、総覧と案内文を確認した。
原文に沿う現代語の再構成、史書が伝える逸話、後世の引用、編集上の読みを区別し、本文と出典の対応を整えた。
底本間の違いは誤りと決めつけず、読み物としての対句や比喩を残した。

## 再校の工程

1. 原文との対照で、意味の取り違え、説明の不足、数値の対象を確認した。
2. 史書・教範・研究論文・図書館目録・施設の公式情報を調べ、年代、人物、伝承と史実の扱いを修正した。
3. 書き下し文を電子本文と1935年刊本の画像で照合し、転記の誤りと刊本の誤植を分けた。
4. 日本語を再読し、生成データの整合性、出典注、実ブラウザの表示と移動を確認した。

`natural-japanese` と、追加された `yomiyasu` を使用した。
`yomiyasu` の検出結果は候補として精査した。文末の反復や否定の並列には、原文の対句や進言の口調に由来するものがあるため、一律には削っていない。

## 書き下し文の補正

底本は鈴木種次郎編、1935年刊『武経七書』所収の孫子。
[電子本文](https://ja.wikisource.org/wiki/孫子_(武経七書))と[刊本画像](https://ja.wikisource.org/wiki/File:Bukyō_shitisyo.pdf)を対照した。
下表は10か所、9段落の補正。頁は刊本の本文頁であり、PDFのページ番号ではない。

| 篇 | 変更前 → 変更後 | 判断・刊本頁 |
| --- | --- | --- |
| 始計 | 將吾が計を聽いて → 將吾が計を聽かず | 刊本にもある誤植。原文「將不聽吾計」の否定を復元（2頁） |
| 作戦 | 覩ざる可き也 → 覩ざる也 | 刊本にもある誤植。原文「未睹」の意味に合わせる（3頁） |
| 作戦 | 糧に敵に因る → 糧は敵に因る | 刊本にもある助詞の誤植（3頁） |
| 兵勢 | 寄正 → 奇正 | 電子本文の転記誤り。刊本は「奇」（7頁） |
| 軍争 | 衆爭 → 軍爭 | 刊本にもある誤植。原文「軍爭」に合わせる（10頁） |
| 地形 | 必ず收る → 必ず敗る | 刊本にもある誤植。原文「必敗」に合わせる（17頁） |
| 九地 | 行くべく.彼れ → 行くべく、彼れ | 電子本文の句読点を補正（18頁） |
| 九地 | 衞地 → 衢地（2か所） | 電子本文の転記誤り。刊本は「衢」（18・20頁） |
| 九地 | 方ベ → 方べ | 片仮名の「ベ」が混入した表記を平仮名に統一（19頁） |

補正を行った六篇には、ページ下部に補正注を表示した。
それ以外の旧字体、歴史的仮名遣い、底本の省略・読みの差は、無断で統一していない。
たとえば謀攻の「少則能守之」は、掲載原文の系統に沿う進言を残した。

## 検証結果

- 原文13篇の配列は、作業開始時の本文から変更していない。中国語版Wikisourceとの対照では、句読点・校異注を除く掲載方針を確認した。
- 書き下し文は上表の10か所だけが変わっていることを機械的に照合した。
- 名句12件を照合した。全文の底本と字句が異なる4件は、名句側の参照本文で確認し、異本差として扱った。
- JavaScript構文、十三篇の件数・ID、名句12件と進言のリンク対象の対応を確認した。
- `bun run build` と `git diff --check` を実施。標準のtest・typecheckスクリプトは本プロジェクトにない。
- 実ブラウザで1440pxと420×912pxを確認。LocalWeb反映後に十三篇をモバイル幅で通覧し、横方向のはみ出し、進言の文字サイズ、出典注を確認した。
- 目次からの移動、名句と進言の往復、書き下し文の横書き・縦書き切り替え、縦組みの送り、附録の画像を確認した。確認中のブラウザ警告・エラーはなかった。
- `sonshi-guide.localhost` と、Tailscale配信用ローカル入口の `/apps/sonshi-guide/` で配信を確認した。

## 確認の限界と次回の手順

史書の逸話を現実に起きた出来事として実証したものではない。典拠に帰属させ、伝承・解釈の断定を抑えた。
『ザ・ソプラノズ』による販売増の当時の記事は、今回その掲載元で全文を再取得できなかった。二次資料でも報道内容を確認し、具体的な販売部数を削った。
ドラマ・映画の台詞は公開された採録を照合したもので、映像本編の全編視聴による検証ではない。
iPhone Air実機と、外部端末からのTailscale接続は未検証。420×912pxはブラウザの表示領域での確認である。

今回もっとも照合に手間がかかったのは、電子本文の誤りと刊本自体の誤植の切り分けだった。
次回はこの補正表と各篇の出典を起点に変更箇所を対照し、新しい主張だけを追加調査すると、同じ確認を繰り返さずに再校できる。

## 追加再校

### 三巡の確認

1. 全文を読み、原文との意味の対応、日本語の自然さ、史料への帰属、年代、出典名とリンクを点検して修正した。
2. 修正後に全文を再読し、文脈・並列表現・指示語・年代区分を確認した。劉秀の見出しと、句読点を除く掲載方針から漏れていた原文の特殊記号を追加修正した。
3. 再修正後の全文と差分を確認し、修正箇所を再び出典と対照した。確認できた範囲では、さらに書き換えるべき明確な問題は見つからなかった。底本差や解釈の幅を、単なる誤りとして統一していない。
