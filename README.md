# 孫子兵法 十三篇

『孫子兵法』の十三篇を、いくつもの層で読むための静的サイトです。

各篇は三つの帖に綴じ分け、一帖ずつめくって読みます。

- 壱「語る」（`#chapter-3` など）：軍師の進言（原文を順に読み、軍師が王に語りかける形に再構成した現代語の本文）
- 弐「原典」（`#chapter-3/genten`）：現代に残る言葉（名句）、原文（縦組み）、書き下し文（横書き／縦書き）
- 参「読み継ぐ」（`#chapter-3/yomitsugu`）：余話（後の時代での読まれ方）と、こんなところにも（後世に引かれた例）

帖ごとに紙面の色づかいを変えています。「語る」は生成りの紙に朱、「原典」は墨を塗った壁のような暗い紙面（暗い表示では青みの墨）、「読み継ぐ」は同じ紙に、後の世の書き込みを思わせる藍を差します。帖札は、広い画面では本文の左の余白に三枚の短冊として掛け、狭い画面では下端に並べます。各帖の末尾からは次の帖へ、最後の帖からは次の篇へ進めます。帖札はどの帖でも帖の頭へ送り、「語る」では扉を飛ばして進言の頭に着きます。

`#overview` の「総覧」では、編紐で綴じた十三本の竹簡を水墨の山並みの前に並べた表紙がそのまま目次になります。竹簡の下には「計る」「形と勢」などのまとまりの名を添えています。その後の「一篇の読み方」からは、第一篇のそれぞれの帖を開けます。`#sonshi` の附録では「孫子という人」を読めます。篇と附録の扉には、和本の題簽のように篇名を縦に掲げ、その篇の書き出しを薄墨で透かしています。閲覧の記録は保存しません。帖をめくって戻ったときの位置、押したリンクへのフォーカス、書き下し文の組み方は、ブラウザの履歴の項目に持たせるだけです。

上端には十三篇を小さな竹簡として右から左へ綴じ、開いている篇の竹簡を引き出して示します。読み進めると上端（狭い画面では下端の帖札も）は退き、戻ろうとするか末尾まで読むと現れます。進言の中で名句にあたる段には、右の余白に名句の名を傍注のように添え、その句から原典の帖の名句へ、名句から進言の中の句へ移れます。

「原典」の帖では、広い画面なら書き下し文の右に原文を掛け、書き下し文を読み進めると原文も同じあたりまで送ります（原文の上でホイールを回してもページが進みます）。書き下し文を縦書きにすると二つの縦組みが並び、書き下し文を繰ると原文も繰られます。原文が送られているあいだは原文の送りの操作を出さず、キーボードの止まり先にもしません。狭い画面では原文を先に、書き下し文を後に置きます。原文と縦書きの書き下し文には「左へ読む」「右へ戻る」を添えています。

狭い画面では「目次」から十三本の竹簡を二段に並べた目次を開けます。表紙の竹簡は横に繰って選べます。

データは `src/chapters.js`（篇と進言）、`src/full-texts.js`（原文・書き下し文）、`src/sayings.js`（名句と進言中の該当箇所）、`src/asides.js`（余話）、`src/person.js`（附録）にあります。`src/templates.js` がデータからHTMLを生成し、`src/app.js` が画面と帖の切り替え・ナビゲーション・本文の操作を受け持ちます。`src/styles.css` は冒頭に色・書体・文字の大きさ・余白・角・影・動きをデザイントークンとして定義し、帖ごとの紙面はトークンの差し替えで切り替えます。表紙の山水 `src/images/ink-landscape.webp` は、画像生成AIで制作した水墨画から墨の濃淡だけを取り出したもので、CSS のマスクとして使い、ライト／ダークどちらでも墨色で描きます。

## 開発

基準ランタイムは Bun 1.4.2 です。

```bash
bun run test
bun run build
localweb dev sonshi-guide
```

ポート番号は LocalWeb が割り当て、`--port` で渡します（`http://sonshi-guide-dev.localhost/`）。

編集対象は `src/`、生成先は `dist/` です。`design/` には制作時のデスクトップ／モバイル参考画像を残しています。

`bun run test` は、全篇の三つの帖の原文・書き下し文、帖札、帖をまたぐ名句と進言のリンク、見出しの参照、帖送りと前後の篇への移動、HTMLのエスケープを検証します。追加のパッケージは不要です。表示・操作は別途実ブラウザで確認します。

## LocalWeb

LocalWeb では `sonshi-guide.localhost` として公開し、Tailscale 経由では `/apps/sonshi-guide/` から参照します。

## 出典

原文・書き下し文と各名句の出典は、各篇の末尾および各名句に表示しています。主な全文参照先は中国語版・日本語版 Wikisource です。
